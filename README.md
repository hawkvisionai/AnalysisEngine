# HawkVision Analysis v2.7｜A 基礎分析雙方忽略和局

## 本版規則
- 會員仍可輸入和局。
- 和局仍顯示在珠盤路、莊閒和統計與總局數中。
- A 基礎分析建立目前序列時，完全移除所有和局。
- Supabase 歷史資料比對時，也完全移除所有和局。
- 歷史「下一局」取下一個非和局結果，因此判定只會是莊或閒。
- 和局仍不計正確、不計錯誤，也不影響連勝／連敗。
- 「最近 N 局」在 A 分析中代表最近 N 個莊／閒結果。

## 更新前必做
先到 Supabase → SQL Editor，執行：
`supabase_A_basic_no_tie.sql`

執行成功後，再將其餘網頁檔案上傳 GitHub Pages。
