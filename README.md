# HawkVision Analysis v2.8｜歷史符合率與信心度分離

這是 GitHub Pages 覆蓋更新版。

## 核心更新

### 本次判定旁的百分比
只顯示「歷史符合率」。

例如歷史相同序列的下一個非和局結果：
- 莊 82 次
- 閒 18 次

會員畫面顯示：
- 本次判定：莊 82%

### 信心度
不再直接等於歷史符合率。

v2.8 第一版公式：
- 40%：歷史符合率
- 40%：歷史資料充足度
- 20%：分析一致性

資料充足度使用平滑飽和曲線，避免資料量剛超過某個門檻時信心度突然跳升。

## 保留規則
- 信心度顯示範圍：30%～90%
- 低於 40% 顯示「信心度過低，不建議下注」
- 會員不會看到歷史樣本數
- A 基礎分析雙方搜尋時完全忽略和局
- 和局仍保留在珠盤路與當下牌靴統計
- 和局不計正確／錯誤，也不影響連勝／連敗
- 保留 F5 分頁暫存、撤銷、載入動畫與判定框變色
